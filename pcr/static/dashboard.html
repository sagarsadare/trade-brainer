TradeBrain / Nifty 50 Put-Call Ratio

The chart plots PCR against time for the selected expiry; points are green at PCR ≥ 1 and red below, matching the signal column exactly. The table lists every 15-minute slot, newest first. Diff is PUT minus CALL open interest, so it carries the same sign as PCR − 1. Option signal is BUY at PCR ≥ 1 and SELL below it. VWAP is a cumulative session VWAP taken from the front-month future — the index itself reports no traded volume, so it cannot supply one; VWAP signal is BUY when price is above it. The PCR column is exactly the series plotted in the curve above.

PCR = Σ PUT / Σ CALL across ATM ±10 strikes, with weekly and monthly expiries tracked separately. OI-PCR uses open interest (positioning); Vol-PCR uses cumulative traded volume (flow) — Vol-PCR reacts faster and is noisier early in the session. The dashed line at 1.00 is the neutral pivot: above it puts dominate, below it calls do.
Dotted curves are the comparison session, aligned by time-of-day. Backfilled sessions begin at 09:30 because a 15-minute candle stamped 09:15 only reports its state at 09:30; live collection additionally captures the 09:15 open.
